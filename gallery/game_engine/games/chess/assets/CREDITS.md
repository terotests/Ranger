# Chess assets

Generated classic Staunton-style piece silhouettes and a felt/wood board
backdrop (not third-party art).

- `pieces.png` — 6×2 sheet (P N B R Q K × white/black), 28×28 frames
- `board_bg.png` — 480×270 green felt with wood rail
- `image.png` — launcher icon

Regenerate:

```bash
npm run engine:chess:assets
```
