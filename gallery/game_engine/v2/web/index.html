The engine compiled to JavaScript, a Monaco editor, and a virtual filesystem shared between them. Edit the game and it hot-reloads — no restart.

canvas — the running game

Try editing a constant near the top of the script (a colour, a speed, a size) and watch the game update. Edits to update/hud keep the running state; edits to initState/sprites rebuild the scene. A connected gamepad works too (d-pad/stick + A), and sound is the engine's own synth played through Web Audio.
