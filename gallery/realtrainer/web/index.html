RealTrainer — a Ranger app painted by EVG's WebGL painter

loading–

A loading screen and the page it hands over to. The tree, the stylesheet, the clock and the hit testing are gallery/realtrainer/src/RealTrainerDemo.rgr; this page hands it the real time between two frames and draws the display list it emits.

The ring

Twelve boxes stacked in one grid cell, each turned about a point 54 px below its own top edge — EVG has no position: absolute, and a one-cell grid is the layout that lets children share a rectangle.

Only the container is turned each frame. A parent's rotation is composed onto every command its subtree emitted, so twelve blades cost one angle.

The gradients

The blades and the bar are two-stop fills, mixed in the fragment shader. The command, the JSON and the shader have carried a gradient all along; until this demo nothing wrote one from an element, so background: linear-gradient(…) came out flat or not at all.

Try it

Wait for the bar, then hover and press Jatka Googlella — the hover fade is a transition in the stylesheet, and the press is EVG's own hit test resolving a coordinate to an id. The button starts the loader again.

A canvas hands a screen reader one empty graphic, so the page also publishes what the frame means: the same tree walked as roles, names and rectangles, mirrored into transparent DOM over the pixels.
