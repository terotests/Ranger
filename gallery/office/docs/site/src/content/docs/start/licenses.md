This site is generated from sources under `gallery/`. Ranger-authored files
under `gallery/` use the GNU Affero General Public License, version 3 or a
later version, unless a file or a directory states a different license.

The pages quote those sources. The class descriptions, the paragraph under a
method and the sentence in a table row are the comments above the
declarations, copied. Those comments are AGPL-3.0-or-later. That is why this
site is not part of the language documentation.

## The language documentation

The [Ranger language documentation](/Ranger/docs/) is MIT. It describes the
compiler and the language. It does not quote gallery comments.

The two licences are different. This site follows the code it describes.

## The compiler

Ranger-authored files outside `gallery/` use the MIT license, unless a file
or a directory states a different license. A program that you write and
compile with Ranger can use the MIT license. A program that imports a gallery
module uses that module, and the AGPL then applies to that program.

## Third-party files

Some files in `gallery/` keep the license of their authors. Each of those
files has its own license file next to it. Fonts under
`gallery/pdf_writer/assets/fonts` keep the SIL Open Font License.
