RangerDBViewer · the database is in this tab

No server, and no database server either. RangerDB is written in Ranger, so it compiles to JavaScript along with the viewer above it and this page really holds a database rather than a picture of one: the tables are created, rows are inserted, the schema is introspected, and the result is drawn DatabaseSchema → RangerFlow → EVGDisplayList → WebGL 2. The strip is the shared EVG toolbar the document, deck and spreadsheet editors use.

RangerDB has no DDL yet, so it cannot describe a foreign key — and it says so in the status line rather than implying the database has none. Press the SQL button on the Schema page to read the same schema from CREATE TABLE text instead: every relationship appears, and there are no rows to browse. Both are real; neither pretends to be the other.
