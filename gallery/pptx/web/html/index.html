What this is

The serverless PPTX editor with one part replaced. The deck is still parsed in this page and still laid out by EVG — OPC/ZIP → PresentationML → theme & layout inheritance → EVGDisplayList — and the display list that comes out is byte-for-byte the one the WebGL page draws. Only the painter differs: gallery/evg/html/evg-html.js turns those commands into an <svg> instead of into quads and a glyph atlas.

There is no <canvas> on this page and no GPU behind it. Every shape on the slide is a real element you can inspect, the text is real text you can select, zooming re-renders instead of blurring, and Print sends vectors rather than a rasterised PNG per slide.

It is a painter, not a port: a draw command carries no id, so every frame rebuilds every node. What that costs, and what a version with element identity would buy, is in gallery/pptx/web/html/README.md.
