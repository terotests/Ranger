Type to edit. Arrow keys move the caret, Control with left or right moves by word, Control with Home or End goes to the start or end of the document. Tab inserts two spaces; press Escape and then Tab to move focus out of the editor. 


    

      

        The editor is Ranger, compiled to JavaScript; the picture is an
        EVG display list drawn by gl/evg-webgl.js on WebGL 2.
        The same page compiles to C++ and draws through OpenGL in the SDL
        binary — npm run datagrid:editor:sdl.
      

      

        Click to place the caret, drag to select, type. Ctrl+K switches
        between the report script and the syntax sampler, Ctrl+L reloads
        it, Ctrl+Z / Ctrl+Y undo and redo, Ctrl+A selects
        all. Paste works.
